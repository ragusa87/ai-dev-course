# Types d'apprentissages
- Apprentissage supervisé: Un  *paquet* de données étiquetées. Diminuer l'erreur
- *Apprentissage par transfert*: Quelques données étiquetées - Le plus important. Utiliser un modèle pré-entraîné et le ré-entraîner sur ses propres données. => Ex: EfficientNet
- Apprentissage auto-supervisé (self-supervised learning): Données non étiquetées
- Apprentissage par renforcement: Pas de données. Apprendre en faisant

## Renforcement Learning
- L'agent demande si on préfère A ou B. Il apprend à partir de nos réponses

## Théorie: Fonctionnement d'un neurone artificiel
- Somme pondérée des entrées
- Fonction d'activation (Relu, Sigmoid, Softmax) 
- Equation mathématique: y = f(w1*x1 + w2*x2 + ... + wn*xn + b)
- Biais: Permet de décaler la fonction d'activation. => Permet de mieux s'adapter aux données.
- Paramètres: Poids et biais
- Poids: Random à l'initialisation, puis ajustés lors de l'entraînement. 
- Hyperparamètres: Paramètres définis par l'utilisateur, Fonction d'activation, taux d'apprentissage, nombre de couches, nombre de neurones par couche, etc.
### Choix de la fonction d'activation
- Au feeling, quelques règles:
- Relu: Très utilisé, rapide, efficace. => ReLU(x) = max(0, x)
- Sigmoid: Pour les sorties entre 0 et 1. => Sigmoid(x) = 1 / (1 + exp(-x))
- Softmax: Pour les sorties multi-classes. => Softmax(xi)
